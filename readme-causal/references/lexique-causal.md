# Lexique causal — termes-clés du skill readme-causal

## Les 4 mouvements

**Anamèse** (grec/français, médical-soutenu) : reconstitution de l'histoire du problème avant tout traitement. Dans un README, c'est la section qui raconte comment le problème s'est manifesté, ce qui existait déjà, et pourquoi c'était insuffisant.

**Étiologie** (français, technique médical) : étude des causes racines. Ne remonte pas au symptôme mais à la cause structurelle. Dans un README, couvre le kairos (pourquoi maintenant) et la nécessitation (pourquoi cette approche plutôt qu'une autre).

**Causal scaffold** (anglais, construction) : ossature causale navigable. Chaque composant de la solution est lié à une contrainte nommée dans l'Étiologie. Pas une liste de fonctionnalités — une architecture justifiée.

**Résidu** (français) : ce qui reste après la solution. Distinct d'une roadmap : trace les exclusions assumées et les compromis délibérés, pas les fonctionnalités futures souhaitées.

## Termes de l'Étiologie

**Kairos** (grec, philosophique) : le moment opportun — la fenêtre étroite où une action peut être efficace. Répond au paradoxe « pourquoi personne n'avait fait ça avant ». Dans un README, répond à : quelle condition récente (technologique, organisationnelle, réglementaire) rend ce projet possible ou nécessaire maintenant ?

**Nécessitation** (français, philosophique) : trace la chaîne de contraintes qui rend la solution inévitable. Pas « on a choisi cette approche » mais « cette suite de contraintes a rendu les autres approches impossibles ».

**Problemstellung** (allemand, philosophique) : installation du problème dans son contexte complet avant toute mention de solution. Rend le saut vers la solution légitime. Correspond approximativement au mouvement Anamèse.

## Sources d'inspiration

- Simon Sinek, *Start With Why* (Golden Circle) — le WHY avant le WHAT et le HOW
- Tom Preston-Werner, *Readme Driven Development* — écrire le README avant le code
- Michael Nygard, *Documenting Architecture Decisions* (ADR) — chaque décision trace son contexte et ses contraintes
